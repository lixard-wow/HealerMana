# HealerMana

Know your healers' mana before the pull goes sideways. HealerMana shows the mana of every healer in your group or raid in one small display, so a glance tells you who's about to run dry.

- **Download:** [CurseForge](https://www.curseforge.com/wow/addons/healermana)
- **User guide:** [lixard-wow.github.io/healermana](https://lixard-wow.github.io/healermana/)
- **Game:** Retail, Midnight
- **Works with:** Holy and Discipline Priest, Restoration Druid, Holy Paladin, Restoration Shaman, Mistweaver Monk and Preservation Evoker

## Features
- Every healer's mana, updated live, as icons or bars.
- Horizontal, vertical or grid layout.
- Out-of-range dimming.
- Class colors and spec icons.
- Dead and Offline labels, a food and drink icon while a healer drinks, and a marker for Druid healers in Cat, Bear or Moonkin Form.
- Turn it on or off for the open world, dungeons, raids, scenarios, battlegrounds and arenas.
- Sort alphabetically or by class.
- Move, resize and lock it.

## Getting started
1. Install the addon and log in.
2. Join a group with a healer. The display appears just right of the middle of your screen.
3. Type `/hm` or click the minimap button to open settings.
4. Drag the display where you want it, then turn on Lock frame.

To set it up without a group, press Start Preview in the settings or type `/hm raid 5`.

## Commands
| Command | What it does |
| --- | --- |
| `/hm` | Open settings |
| `/hm lock` | Lock or unlock the display |
| `/hm alpha` | Sort healers alphabetically |
| `/hm class` | Sort healers by class |
| `/hm layout` | Switch between horizontal and vertical |
| `/hm reset` | Put the display back in its default position |
| `/hm raid 5` | Show fake healers to preview a layout (up to 20) |
| `/hm raid off` | Go back to your real group |
| `/hm help` | List the commands in chat |

`/healermana` works the same as `/hm`.
